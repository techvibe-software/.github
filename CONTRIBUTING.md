# Contributing to Techvibe Projects

Thank you for your interest in contributing to Techvibe open-source repositories! We welcome pull requests, bug reports, and suggestions from developers worldwide.

---

## Code of Conduct

- Be respectful, constructive, and collaborative in discussions, issues, and code reviews.
- Focus on practical, clean, and well-tested solutions.

---

## How to Contribute

1. **Fork the repository** and clone your fork locally.
2. **Create a branch** with a descriptive name (`git checkout -b feat/your-feature-name` or `fix/issue-description`).
3. **Make your changes:**
   - Adhere to the existing project code style and TypeScript / Python standards.
   - Add unit tests for any new logic or bug fixes.
   - Ensure all automated tests and type-checks pass locally (`npm test` or `bun test`).
4. **Commit with clean commit messages** following Conventional Commits format (`feat: ...`, `fix: ...`, `docs: ...`).
5. **Open a Pull Request** against the `main` branch with a clear description of the problem and solution.

---

## Questions?

Feel free to open an issue or reach out at [info@techvibe.ir](mailto:info@techvibe.ir).
