# Security Policy

## Supported Versions

Techvibe maintains and publishes security updates for the latest major versions of all open-source libraries and production systems.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within any Techvibe project or service, please disclose it responsibly:

1. **Email:** Send details directly to [security@techvibe.ir](mailto:security@techvibe.ir) or [info@techvibe.ir](mailto:info@techvibe.ir).
2. **Details:** Include steps to reproduce, affected versions, and potential impact.
3. **Response Time:** We acknowledge reports within 48 hours and work on remediation promptly.

Please do not open public GitHub issues for sensitive security vulnerabilities before a patch has been published.
